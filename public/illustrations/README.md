# AZ Group — иллюстрации

Плоские геометрические SVG, нарисованные вручную. Палитра: фирменный красный `#cd0929` (тёмный `#a80722`, мягкий `#fdecef`), чернила `#1d1f23`, серые `#f0f2f4` / `#e4e7eb`, акценты направлений — робототехника `#4f47b7`, международные программы `#187d77`. Без текста, шрифтов и внешних ресурсов; в каждом файле есть `<title>`, `role="img"` и `viewBox` (масштабируются без потерь). Фон прозрачный, файлы рассчитаны на светлую подложку.

Подключение: `<img src="/illustrations/dir-science.svg" alt="…" width="240" height="240" loading="lazy">`. Если изображение чисто декоративное (рядом есть заголовок с тем же смыслом), используйте `alt=""`.
