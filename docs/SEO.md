# SEO сайта AZ Group: ключевые слова, конкуренты, разметка

Дата анализа: 24.10.2026. Что сделано в коде — в конце файла.

## Как устроено SEO на сайте

- **Тексты разделов** — `t.seo.pages[раздел]` в `src/i18n/ui/{ru,kk,en}.ts`: `title` (вкладка и сниппет), `description`, `keywords`. Меняются там же, где и остальные подписи; все три языка обязаны иметь одинаковые ключи (TypeScript проверит).
- **H1 разделов** — `t.nav[раздел].title` (там же). Подпись в меню (`label`) — короткая, H1 — с ключевыми словами.
- **Рантайм** — `src/components/Seo.tsx` (`useSeo`): `<html lang>`, title, description, keywords, robots, Open Graph (в т.ч. `og:image` новости, `article:*`), canonical, `hreflang` для ru/kk/en/x-default и JSON-LD.
- **JSON-LD** — `src/components/jsonld.ts`, собирается в `src/App.tsx`: `Organization`+`EducationalOrganization`, `WebSite` c `SearchAction` (поиск по календарю `/events?q=`), `BreadcrumbList`, `WebPage`, `EducationEvent` для будущих событий календаря (дата, место, цена, ссылка регистрации), `FAQPage` для «Вопросов», `NewsArticle` для новости, `ItemList` для ленты, `Brand` для проектов. В `index.html` — статическая `Organization` (видна до запуска скриптов) и `<noscript>` с H1, кратким описанием и ссылками на разделы и языки.
- **Sitemap** — `GET /api/sitemap.xml` (`server/routes/sitemap.ts`), на Vercel доступен как `/sitemap.xml`: разделы × языки с `hreflang`, новости с текстом (`/news?id=N`), `lastmod` по дате изменения в базе. Новый раздел добавляйте в `SITE_ROUTES` (`shared/routes.ts`).
- **robots.txt** — закрывает `/admin` и `/api`, `Clean-param` склеивает фильтры календаря (`?q=`, `?programs=`) для Яндекса.
- **Откуда приходят заявки** — форма отправляет язык страницы, источник перехода и UTM-метки первого визита (`src/content/visit.ts`); в админке это видно в карточке и таблице заявок, в CSV и в сводке «Источники заявок» на дашборде. Размечайте ссылки в рекламе и соцсетях `utm_source/utm_medium/utm_campaign/utm_term` — тогда будет видно, какие запросы и каналы приводят заявки.

Проверка: [Google Rich Results Test](https://search.google.com/test/rich-results), [Яндекс Вебмастер → Проверка микроразметки](https://webmaster.yandex.ru/tools/microtest/). После деплоя отправьте `https://www.azgroup.kz/sitemap.xml` в Google Search Console и Яндекс Вебмастер.

## Старый сайт az-group.kz: что было и что перенесено (25.10.2026)

Аудит старого сайта (Nuxt, язык через cookie, адреса без языкового префикса):

| Что | На старом сайте |
|---|---|
| title | «AZ Group» на всех страницах и языках; свой только у «Публичной оферты» и входа («Вход • Optimus») |
| description | одно русское описание на всех страницах и языках (кроме оферты) |
| keywords | один русский набор: AZ Group, олимпиады, Fibonacci olympiads, робототехника, Astana Tech Cup, образовательные проекты, Казахстан, международные программы, лагеря, олимпиады по математике, конкурсы, грант, научная конференция |
| Open Graph | только на оферте (og:title, og:description), без картинки |
| canonical, hreflang, JSON-LD | нет |
| robots.txt, sitemap.xml | нет (404) |
| Счётчики, verification-метки | нет |
| Иконка | favicon.ico 16–48 px (белые «AZ» на чёрном) |
| Страницы | `/`, `/events`, `/news/<id>`, `/public-offer`, `/auth`; новости — только на русском (kk/en отдают русский текст) |

Перенесено в новый сайт:
- **Тексты всех 6 новостей** (`/news/1…5, 12`): русский оригинал (исправлены опечатки, разбит на абзацы) + переводы kk и en. В коде — `src/data/site.ts` и `src/i18n/content/{kk,en}.ts` (сид и статика), в рабочей базе — миграция данных `0005_news_bodies` (заполняет только пустые тексты, правки из админки не трогает; применяется сама при production-деплое). Каждая новость теперь — отдельная страница на трёх языках с `NewsArticle`, картинкой в og:image и адресом в sitemap.
- **Описание компании** старого сайта — description страницы «О компании» (ru, плюс перевод kk/en).
- **Все ключевые слова** старого сайта и формулировки его разделов и проектов («Соревнования», «Календарь событий», «Международная научная конференция ITECX», «Республиканский чемпионат по робототехнике Astana Tech Cup», «Зарубежные лагеря International Camp», «Международные программы обмена Fibonacci Exchange Program» и т.д.) — в keywords разделов на трёх языках и в статических keywords `index.html`.
- **Иконки**: `favicon.ico` (16/32/48), `apple-touch-icon.png`, `icon-192/512.png` и `site.webmanifest` — в фирменном стиле нового сайта (серая A, красная Z); растровый логотип для JSON-LD (Google не принимает SVG).
- **Старые адреса новостей**: `/news/<id>` → 301 на `/news?id=<id>` (`vercel.json`) — на случай, если домен az-group.kz переведут на новый сайт или ссылки старого формата попадут на azgroup.kz.

Не переносилось: «Публичная оферта» и вход в личный кабинет (`/public-offer`, `/auth`) остаются на az-group.kz — там регистрация и оплата, новый сайт на них ссылается.
