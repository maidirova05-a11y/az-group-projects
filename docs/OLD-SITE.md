# Старый сайт az-group.kz ↔ основной сайт www.azgroup.kz

С 25.10.2026 всё, что посетитель делал на старом сайте, работает на основном:

| Было на az-group.kz | Теперь на www.azgroup.kz |
|---|---|
| `/events` + личный кабинет `/auth` — регистрация на мероприятия | `/register` — анкета участника, оплата через Kaspi (ссылка программы), регистрации — в админке «Регистрации» |
| `/public-offer` — публичная оферта | `/offer` (ru/kk/en, тот же текст) |
| `/news/<номер>` — новости | `/news?id=<id>` (тексты перенесены, kk/en переведены) |
| `/` | `/` |

В коде и в базе не осталось ссылок на страницы старого сайта (кроме e-mail info@az-group.kz). Миграция данных `0007_move_from_old_site` меняет старые ссылки в настройках, мероприятиях и вопросах на рабочей базе при деплое.

## Как сайты связаны для поисковиков

Уже работает (в этом проекте):
1. **Старые адреса на основном домене** (`vercel.json` → `redirects`): `/news/<номер на старом сайте>` → 301 на новую страницу новости (сопоставление по `news.legacy_id` в `GET /api/legacy/news/:id`, с языком: `/kk/news/12` → `/kk/news?id=…`), `/public-offer` → `/offer`, `/auth` → `/register`.
2. **Постраничные 301 с домена az-group.kz** (`vercel.json`, правила с `has: host = (www.)?az-group.kz`): `/` → `/`, `/events` → `/events`, `/news/<номер>` → новость, `/public-offer` → `/offer`, `/auth` → `/register`, остальное → тот же путь на www.azgroup.kz. **Они включатся, как только домен az-group.kz будет подключён к этому проекту в Vercel** (см. ниже) — до этого правила просто не срабатывают.
3. **Организация в JSON-LD** указывает старый сайт в `sameAs` — Google и Яндекс понимают, что это один бренд.

Что нужно сделать вам (вне кода):
1. **Перевести домен.** Vercel → проект → Settings → Domains → Add `az-group.kz` и `www.az-group.kz`, затем у регистратора домена поменять DNS-записи на те, что покажет Vercel. После этого все ссылки на старый сайт (в поиске, соцсетях, буклетах) будут вести постранично на новый с кодом 301 — вес ссылок и позиции переходят на www.azgroup.kz.
   - Перед переводом убедитесь, что старый личный кабинет больше не нужен участникам (старые регистрации и оплаты сезона 2025–2026 остаются в базе старого сайта: azgroupv2.abmco.kz). При необходимости выгрузите их у разработчиков старого сайта.
2. **Сообщить поисковикам о переезде** (после того, как редиректы заработают):
   - Google Search Console: добавьте оба ресурса (az-group.kz и www.azgroup.kz), подтвердите права и в ресурсе az-group.kz откройте «Настройки → Изменение адреса» → укажите www.azgroup.kz.
   - Яндекс Вебмастер: добавьте оба сайта, в старом — «Индексирование → Переезд сайта» → www.azgroup.kz. Отправьте `https://www.azgroup.kz/sitemap.xml` в обоих сервисах.
3. **Если старый сайт пока должен оставаться на своём сервере**, попросите его разработчиков (abmco.kz) добавить на страницы старого сайта:
   - `<link rel="canonical" href="https://www.azgroup.kz/…">` по таблице выше. Для новостей canonical — конечный адрес `https://www.azgroup.kz/news?id=<id>`; соответствие номеров даёт запрос `select legacy_id, id from news` к базе основного сайта;
   - заметную ссылку на www.azgroup.kz в шапке и в подвале;
   - или сразу настроить 301 на своём сервере по той же таблице.
