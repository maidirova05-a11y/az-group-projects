# AZ Group — заметки для Claude (читаются в начале каждой сессии)

Язык общения с владельцем — русский. Владелец не разработчик: команды для сервера давать готовыми блоками, по шагам, объяснять, в каком окне их выполнять. Секреты (пароли, JWT, ключи, строки подключения) в репозиторий и в чат не писать. **Репозиторий публичный: не добавлять сюда IP-адреса, учётные данные, список других проектов на сервере и прочие детали инфраструктуры** (они хранятся отдельно, у владельца).

**Подробности сервера и планов хранятся в приватном репозитории `maidirova05-a11y/az_infra` (`CLAUDE.md`).** Если в этой сессии его нет, а задача касается сервера, деплоя или других проектов владельца, попросить подключить `az_infra`.

## Проект
Сайт AZ Group (https://www.azgroup.kz) + админка `/admin`: React/Vite, API на Hono, PostgreSQL + Drizzle. Подробности — `README.md`, `docs/ARCHITECTURE.md`. Языки сайта: ru (без префикса), kk, en. Политика конфиденциальности (`/privacy`) и согласие законного представителя — `src/data/privacy.ts`, форма регистрации — `src/pages/Register.tsx`.

## Хостинг
С 03.11.2026 сайт работает на VPS Hoster.kz (Астана), а не на Vercel; устройство и настройка — `docs/HOSTER-KZ.md`, скрипты — `deploy/`. Сервер общий с другими проектами владельца: их не трогать, у нашего сайта свои пользователь, база, порт и nginx-сайт (см. `docs/HOSTER-KZ.md`).

- У Claude **нет доступа к серверу**: все серверные команды выполняет владелец по инструкциям Claude.
- **Автодеплой:** слияние в `main` попадает на боевой сайт примерно за 2 минуты (`deploy/auto-deploy.sh`, cron на сервере). Упавший деплой оставляет прежнюю версию. Журнал на сервере: `/var/log/azgroup-deploy.log`.
- Данные участников (в том числе детей) должны храниться только на территории РК: старые копии базы в Neon и проект на Vercel подлежат удалению после периода стабильной работы.

## Работа с git
Разработка в ветке, указанной в задаче сессии; PR создавать и сливать только по просьбе владельца. Перед пушем: `npx tsc --noEmit`, `npx vite build`, `node scripts/csp-hashes.mjs --check` (при правке inline-скриптов в `index.html`/`admin.html` обновить хэши CSP в `vercel.json`: `server/prod.ts` берёт CSP оттуда). Тесты `npm test` требуют локальную БД, в облачной среде не запускаются. Не использовать `pkill -f`/`pgrep -f` по имени, встречающемуся в собственной команде (убивает оболочку).
